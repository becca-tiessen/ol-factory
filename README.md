# ol-factory

A cozy 2D perfume-making game built with Godot 4.x and GDScript.

Explore a French village, gather ingredients, mix blends at the mixing bench, age them in the cellar, and deliver perfumes to fulfill NPC requests.

## Running

Open the project in Godot 4.5+ and press F5.

## Reset save data

To clear all game state and start fresh:

```bash
rm ~/Library/Application\ Support/Godot/app_userdata/ol-factory/*.json
```
